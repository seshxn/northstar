# Architecture Decision Records

This directory records the significant architectural decisions made in Northstar. Each ADR captures the context, the decision, the alternatives that were considered, and the consequences.

ADRs are numbered sequentially. Superseded decisions are kept for historical context; new ADRs reference the ones they replace.

| [0004](0004-adapter-registry-pattern.md) | Adapter and registry pattern for runtimes and trackers | Accepted |
